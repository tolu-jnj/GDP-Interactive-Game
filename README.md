# GDP Interactive Game

An interactive training game for Good Documentation Practice (GDP) in GMP environments, focusing on lentiviral vector operations.

## Features

- Interactive modules covering key GDP concepts
- Real-time feedback and scoring
- Progress tracking with badges
- Mobile-friendly interface
- Accessible design with screen reader support
- High contrast mode available

## Modules

1. Gowning & Prep
2. Cell Culture & Inoculation
3. Harvest & Clarification
4. Purification & Calculations
5. Filling & Inspection
6. De-Gowning & Documentation Review

## Technologies Used

- Pure JavaScript (no frameworks)
- HTML5
- CSS3
- Local Storage for progress saving
- Accessible ARIA attributes

## Getting Started

Visit the live game at: https://tolu-jnj.github.io/GDP-Interactive-Game/

## Development

To run locally:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000 in your browser.
